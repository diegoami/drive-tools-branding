Privacy policy

Effective 23 October 2026 · Maintainer: Diego Amicabile

This policy describes Diego’s Drive Tools, a personal Google OAuth application used with rclone on the owner’s managed computers. This website supplies information about that application.

Data accessed and purpose

The configured Google Drive permission is full Drive access. Depending on the commands run, rclone can access file and folder names, identifiers, metadata, and file contents, and can create, modify, or delete items. The application is used to transfer and organize files selected for personal development and research workflows.

Credentials and storage

Google issues OAuth access and refresh tokens after authorization. Credentials are stored in rclone configuration files on the owner’s managed computers; authorized copies of those configurations may be maintained on the owner’s other computers. They are not part of this public website or its source repository. Local file permissions are used to restrict access.

Downloaded files remain on the selected destination computers. Uploaded files remain in the selected Google Drive account. Transfer logs and diagnostics may contain file names, paths, and error details. Retention depends on the owner’s project and backup practices; this utility does not impose an automatic deletion period.

Sharing and third parties

Transfers communicate with Google Drive through rclone and the computers or destinations selected by the owner. Files or credentials may be copied between the owner’s authorized computers. There is no separate application-operated cloud storage service. Sharing outside that workflow requires a separate action by the owner. This application does not sell Google user data or use it for advertising.

Use of Google API data is subject to the Google API Services User Data Policy, including its Limited Use requirements. rclone is a separate open-source tool; see its documentation for its behavior.

This website

This static website does not contain a Google sign-in flow, receive OAuth tokens, or include forms, analytics scripts, or advertising. GitHub Pages hosts it and may process ordinary request information, such as IP addresses, under GitHub’s privacy statement. External links lead to services with their own policies.

Revoke access and remove copies

Revoke this application in Google Account connections to prevent future authorized access. Separately remove stored credentials and any unwanted local or Drive file copies. Revocation does not automatically erase files or backups already created.

Questions and changes

Contact the maintainer through the project’s GitHub issues. Do not post tokens, client secrets, or private files. Changes to data practices will be reflected here with an updated effective date. The OAuth consent screen also provides the configured support email.
