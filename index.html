Diego’s Drive Tools is a personal Google OAuth application used with rclone to move project artifacts between an authorized Google Drive account and the owner’s computers.

Your computer↔rclone↔Google Drive

A desktop workflow, with access you authorize.

A small tool for a practical workflow.

01 / AUTHORIZE

Connect your account

The Google authorization screen explains the requested access. rclone stores the resulting credentials on the owner’s managed computers.

02 / TRANSFER

Work with project artifacts

Use rclone commands to list, download, upload, or synchronize the files needed for personal development and research projects.

03 / CONTROL

Choose what runs

File operations happen through the desktop tools you run. This website is informational and does not request access to your Google account.

Access & responsibility

Understand the permission.

The current Drive configuration requests full Google Drive access. That permission can allow reading, creating, editing, and deleting files; the actual operation depends on the command you run.

Project artifacts may include archives, screenshots, saves, and other files chosen for transfer. This is a personal utility maintained by Diego Amicabile, rather than a public file-hosting service.

You can revoke the application’s access at any time in your Google Account connections. Revoking access does not delete copies already downloaded.

Everything in the open.

Learn how data is handled, read the terms, or ask a question about the project. Please keep credentials and private files out of public issues.
